Responsible Use

This platform is designed exclusively for educational purposes. All student record lookups performed in demo mode use synthetic test data that does not correspond to real institutional accounts or credentials.

No real student passwords, private records, or sensitive personal credentials are collected, stored, or transmitted. The tool demonstrates how lookup databases and API-driven verification function in an ethical, controlled laboratory environment.

A matching lookup result reflects indexed database knowledge; it does not independently verify student identity, account ownership, or system authorization.
