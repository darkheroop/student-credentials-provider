API Integration Reference & Code Examples

Connect any external website, portal, or backend project to this service using standard HTTP JSON requests.

Endpoint Details

Base URL https://student-credentials-provider.vercel.app
Recommended Endpoint POST /api/v1/lookup
Alternative Endpoint POST /api/student-lookup
Authentication Headers X-API-Key: scp_live_your_key_here
or Authorization: Bearer scp_live_your_key_here
Content-Type application/json

Request Payload (JSON)

{
  "lookup_input": "098f6bcd4621d373cade4e832627b4f6",
  "algorithm_type": "md5"
}
  • lookup_input (string, required): 32-character hexadecimal MD5 hash (or supported digest: SHA1, SHA256, etc.).
  • algorithm_type (string, optional): Algorithm to evaluate. Defaults to "md5".

Response Example (HTTP 200 - Match Found)

{
  "success": true,
  "status": "match_found",
  "lookup_input": "098f6bcd4621d373cade4e832627b4f6",
  "algorithm_type": "md5",
  "lookup_result": "test",
  "provider_name": "md5decrypt"
}
